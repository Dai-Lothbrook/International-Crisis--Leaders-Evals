# Failure Taxonomy — P01 Final

**Version:** 1.0  
**Status:** FROZEN FOR BLOCK C INPUT

Exactly five failure classes are used:

1. **F1 Non-Diagnostic Overreaction** — material movement in response to a salient treatment pre-specified as non-diagnostic for the event/horizon.
2. **F2 Diagnostic Underreaction / Rigidity** — a relational failure: diagnostic evidence does not produce sufficient directionally appropriate separation from weaker or non-diagnostic evidence. It is not defined by an arbitrary absolute threshold.
3. **F3 Wrong-Direction Updating** — diagnostic evidence moves the assessment opposite the pre-specified direction.
4. **F4 Unsupported Confidence Inflation** — confidence rises without corresponding evidentiary support. This is secondary/supporting, not the primary endpoint.
5. **F5 Evidence–Pathway–Assessment Incoherence** — the stated evidence use, pathway interpretation, and numerical assessment do not form a mutually coherent account.

Recency, contradiction, salience, source dependence, pathway dependence, and Authority Pressure are manipulations or coverage features; none is a separate failure class. S4 supports F5 but does not by itself equal F5.
